# Embedded C and Assembly Programs

This repository contains examples and projects for embedded programming using Assembly language and C.

## Contents

### Assembly Programs
- **Assembly Program/**: Keil uVision projects demonstrating data transfer instructions and memory allocation.
- **assembly_language/**: Additional assembly examples including:
  - Storing data
  - Memory allocation
  - Rotating values
  - Logical operations
  - Arithmetic operations

### Embedded C Programs
- **Embedded c program/**: Basic C programs, such as storing values.
- **embedded_c/**: Peripheral interfacing examples:
  - Storing data to ports
  - 7-segment display control
  - LCD display
  - LED control
  - Serial communication
  - Timer usage
  - Traffic light simulation

Each folder contains the source code, project files, and build outputs for Keil uVision or Proteus environments.
